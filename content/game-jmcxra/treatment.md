# 明天再拯救世界！　第一部：魔王今天也在加班

一句話：連村口的雞都打不贏的冒牌勇者洛可，接到的第一份委託是「八天內把外賣送到魔王城，順便打倒魔王」。送到之後他才發現，魔王一直在扮演壞人，替一個躲在月亮裡、不敢說再見的小女孩爭取時間。
主題：真相不一定讓人輕鬆，但只有知道真相的人，才能真正做選擇。
第一部核心問題：月亮為什麼在倒數？魔王真的是壞人嗎？
- 問題在第 1 章第 2 分鐘由考官提出。
- 第 3 章結尾回答：倒數是小女孩露米的願望正在變弱；魔王是在替她爭取時間。
預估時長：約 60 分鐘（3 章，每章 19～21 分鐘；每章附事件估時）
平台改編：原企劃是 12～18 小時的回合制 RPG。這是第一部，沒有戰鬥，每章一場「對話戰鬥」（觀察、出示證據、換一種說法）。第二部（黃昏村、勇者之墓、月亮）之後以擴充章節製作。第一部埋下的伏筆都在第一部回收；結局會留下通往第二部的懸念，但第一部的核心問題本身已經回答。

## 全局設計

- **開場鉤子（H1）**
  - 第 1 分鐘：考官問「勇者最重要的能力是什麼？」，回答「準時下班」讓加班四十年的考官感動落淚，洛可合格。
  - 第 2 分鐘：考官發下委託：「八天內把這份外賣送到魔王城，順便打倒魔王。月亮上的倒數停了，你就是正式勇者。」月亮浮出 8。
  - 第一個小目標由村長說出：「勇者總得有把劍。聖劍掉進王宮廚房的馬鈴薯堆了。」
- **玩家原本相信的真相**：倒數是魔王的詛咒。線索包括村民傳言、委託書、魔王城的倒數月曆、龍族人資長的說法。
- **指向真相的線索（公平伏筆）**
  - 第 1 章：骨吉夢裡的搖籃曲。
  - 第 2 章：教授筆記上有一張小女孩的塗鴉，旁邊寫著「請不要讓他知道」。
  - 第 3 章：魔王桌上蓋著的照片、陽台上的自言自語。
- **翻轉（H5、H6）**：第 3 章失物招領處，露米的信揭露真相。翻轉來自外部世界，主角從未違背玩家意志。
- **賭注升級（H2）**：每章的衝突類型都不同。
  1. 自己的面子（考試）
  2. 一族龍的生計（勞資談判）
  3. 魔王的秘密與一個小女孩的命運（信任）
- **語氣（X7）**：第 1～2 章是職場荒謬喜劇；第 3 章前半維持笑點（預約制討伐、三份表格），後半開始帶苦澀。每章各有一個笑點高潮與一個情緒高點；第 3 章揭露前，留一段骨吉在失物招領處獨處的停頓（E2）。
- **玩法輪替（H7）**：每章兩條互不依賴的調查線（不限順序）→ 一場對話戰鬥 → 一個關鍵抉擇；並穿插可選支線與調查點。
- **三個變數（每個兩難的兩邊各加不同變數，總影響相同）**
  - trust：隊友與魔王對你的信任
  - people：民心，村民與龍族的支持
  - bonds：羈絆，你珍惜的回憶與人物支線
- **提示（H17）**：每章指定一位提示者，事件頁依 hint 變數切換三段：輕推 → 重述線索 → 直接說出物件與地點。

## 第 1 章：勇者資格考，史萊姆零分（20 分鐘）

**事件估時**

| 事件 | 時間 |
|---|---|
| 資格考與委託 | 2 分 |
| 村莊探索（告示、奶奶家、麵包店櫃台、小幽靈） | 4 分 |
| 線 A：村長的假牙 → 認識骨吉 | 4 分 |
| 線 B：麵包店 → 對話戰鬥 → 認識米菈 | 5 分 |
| 廚房的寶箱怪與抉擇 | 3 分 |
| 營火（停頓與懸念） | 2 分 |

- **起承轉合**
  - 起：合格並接下委託；開場對話交代木劍是爸爸親手削的。
  - 承：兩條線各帶出一位隊友。
  - 轉：聖劍被廚房的寶箱怪吞了。
  - 合：營火邊，隊伍成立。
- **調查線（不限順序）**
  - A：村長的假牙。在廚房地窖當臨時會計的骨吉，要拿假牙去「對帳」，他是因為好奇洛可的委託才跟上的。
  - B：麵包店被「邪惡法式長棍麵包」堵住門，米菈因此領不到外賣報酬。
- **對話戰鬥：邪惡法式長棍麵包**
  - 攻擊無效（笑點）；施法只會讓它更硬。
  - 把奶奶給的熱湯倒上去，它就變軟並道歉。
  - H10：先看到麵包擋門，奶奶才說「冷掉的東西泡湯就軟了」。
- **提示者**：奶奶（湯）、米菈（寶箱怪）。
- **關鍵抉擇（兩難）**：寶箱怪要一樣「有回憶的東西」換聖劍。
  - 交出爸爸削的木劍、換回聖劍：people +1。第 2 章人資長看到聖劍會讓步，多一條捷徑；但骨吉會小聲說「那是你爸爸的心意吧」。
  - 留下木劍、放棄聖劍：bonds +1。第 3 章對話戰鬥可以用「木劍的回憶」；但之後大家叫你「木劍勇者」。
  - 開關：kept_wooden_sword。
- **章末懸念**：骨吉唱出一段搖籃曲，眼眶冒出藍色火焰：「我好像忘記了一個很重要的人。」月亮的數字變成 7，村民說：「是魔王的詛咒。」
- **地圖**：village（新手村，peaceful）、kitchen（王宮廚房，室內，lively）。

## 第 2 章：龍族勞動權益保衛戰（19 分鐘）

**事件估時**

| 事件 | 時間 |
|---|---|
| 罷工現場、教授加入 | 3 分 |
| 線 A：失蹤的龍蛋 | 4 分 |
| 線 B：連署書（第三位龍有兩種解法） | 4 分 |
| 人資長對話戰鬥 | 4 分 |
| 抉擇與懸念 | 2 分 |
| 支線與調查點（龍洞壁畫、小幽靈） | 2 分 |

- **起承轉合**
  - 起：要取得去魔王城的通行證，得先解決龍族罷工。噗噗教授在山上找遺失的研究筆記，因此加入。
  - 承：龍是王國聘來的固定劇情怪物，一天工作二十三小時。
  - 轉：人資長說「這都是魔王的詛咒害的，月亮倒數一到，大家都得加班」，但他的檔案裡夾著一張魔王城預約表，預約人寫著「洛可・零」。
  - 合：解決罷工，拿到通行證。
- **調查線**
  - A：失蹤的龍蛋，被藏在人資長的檔案櫃當「留任獎金」。找到龍蛋時，一起找到教授的筆記，上面有小女孩的塗鴉與「請不要讓他知道」。
  - B：第三位龍不肯連署。可以用教授的文獻說服牠，或交出麵包師的麵包（牠很餓）。
- **對話戰鬥：龍族人資長**
  - 每回合出示一條規章，玩家要用證據反駁：連署書、龍蛋、王國合約。
  - 證據用錯會扣「績效」，扣到 0 時人資長會重講一次規章，不會卡關。
  - 持有聖劍可以直接要求讓步（捷徑），但人資長會冷冷記一筆「濫用權威」，結局尾聲回收。
- **提示者**：教授。
- **關鍵抉擇（兩難）**
  - 支持龍族自由：bonds +1。龍成為朋友，第 3 章載隊伍到魔王城；但王國的觀光收入會垮，麵包師說明天要漲價。
  - 維持制度：people +1。村民生計得以保住，龍族會撥一位員工護送你；但教授說「我不會忘記這件事」。
  - 開關：dragons_free。
- **章末懸念**：月亮的數字變成 6。預約表背面寫著「請準時，我等你很久了」。
- **地圖**：dragon_peak（龍之山，adventure）。

## 第 3 章：魔王城的員工旅遊（21 分鐘）

**事件估時**

| 事件 | 時間 |
|---|---|
| 抵達，接待員說「洛可先生，您準時了」 | 2 分 |
| 線 A：修電梯 | 3 分 |
| 線 B：績效報告 | 3 分 |
| 送外賣、喝茶、陽台證據 | 3 分 |
| 魔王的抉擇 | 2 分 |
| 地下室的牆與失物招領處 | 4 分 |
| 遺忘管理員對話戰鬥 | 2 分 |
| 露米的信與最終選擇 | 2 分 |

- **起承轉合**
  - 起：魔王城沒有守衛，只有骷髏接待員問「請問預約哪一種討伐方案？」
  - 承：要見魔王，得先修好電梯、交出年度績效報告（笑點）。
  - 轉：魔王收下外賣、請大家喝茶，陽台上的證據顯示他每年都在雇勇者來假打。
  - 合：地下室的牆後面是失物招領處，露米的信揭露真相。
- **調查線（不限順序）**
  - A：修電梯，零件在三層樓；提示者是骷髏接待員。
  - B：替魔王手下填績效報告。每個手下的回答都是小笑點，也藏著「每年都在重複同一天」的線索。
- **魔王的秘密**
  - 喝茶時可以調查桌上蓋著的照片（一個小女孩）。
  - 陽台上有證據：魔王每年雇勇者來假打，並向村民收討伐稅；帳本寫明稅金用來付勇者的演出費和「月亮維修費」。魔王對著月亮說：「再給我一點時間。」
- **關鍵抉擇 1（兩難）**
  - 揭發他：people +1。村民不必再繳稅，但月亮的維修費斷了，倒數會多跳一格。
  - 答應保密：trust +1。魔王說：「將來在拯救世界與拯救一個人之間選擇時，先聽完那個人的故事。」
  - 開關：heard_monday。
- **失物招領處**
  - 只有洛可推得開地下室的牆，接待員說：「是魔王替你預約的，他在找一個不在預言裡的人。」
  - 西裝兔子管理員要求每件失物填三份表格。
  - 可以調查：奶奶亡夫沒寄出的信、麵包店的收據、告示原稿、小幽靈的名字抽屜。
- **對話戰鬥：遺忘管理員**
  - 它會一個一個封鎖選項；可以用回憶解封（木劍、奶奶的湯、龍蛋），不會卡關。
  - 在這之前，骨吉獨自站在搖籃曲的樂譜前，是一段停頓。
- **翻轉**：露米的信寫著「如果明天永遠不會結束，大家是不是就能永遠在一起？」信裡夾著和魔王那張一樣的照片，畫著教授筆記上的「橘子龍」。骨吉想起來了：他曾答應每天陪她唱歌。
- **最終選擇（第一部的關鍵兩難）**：月亮的數字變成 4（揭發魔王時是 3），魔王追了下來。
  - A「把真相告訴大家，一起想辦法」
  - B「先保護魔王的秘密，自己去找露米」
  - C「這不關我的事，我只是來送外賣的」

## 結局判定（F1：結局由最後的選擇加上累積的變數共同決定）

| 順序 | 條件 | 結局 |
|---|---|---|
| 1 | 選 C；或三個變數中至少兩個 ≤ 0（玩家一路都在逃避） | **永遠的星期一**（悲劇） |
| 2 | 選 A，且 people ≥ 2，且 trust 或 bonds 任一 ≥ 1 | **明天，大家一起想辦法**（真結局） |
| 3 | 選 B，且 trust ≥ 1 且 bonds ≥ 1 | **只有我們知道的秘密**（羈絆結局） |
| 4 | 選 A 或 B 但未達條件 | **還沒準備好的勇者**（苦澀結局） |

- 選 C 時，魔王說「我明白了」，一切照舊；這是由選擇加上「洛可願意承擔多少」所決定的悲劇。
- 選 A、B 的條件都需要兩個以上的變數，不是只看最後一個選擇。

**可達性表（每個結局至少兩種達成組合）**

| 結局 | 組合 1 | 組合 2 |
|---|---|---|
| 真結局 | 交出木劍（people）、維持制度（people）、保密（trust），選 A | 交出木劍（people）、揭發（people）、龍族自由（bonds），選 A |
| 羈絆結局 | 留木劍（bonds）、保密（trust），選 B | 龍族自由（bonds）、保密（trust）、交出木劍，選 B |
| 苦澀結局 | 留木劍、龍族自由、揭發（bonds 2、people 1），選 A | 交出木劍、維持制度、揭發（people 3、trust 0、bonds 0），選 B |
| 悲劇 | 任何組合選 C | 三個變數只有一個 > 0 時，選 A 或 B 也會滑向悲劇的版本 |

## 結局內容（每個結局開頭寫月亮數字的去向，並交代洛可、骨吉、教授、米菈、魔王）

- **明天，大家一起想辦法（bittersweet）**：數字停在 4，不再往下跳。
  - 洛可在村民大會上說出真相，村民第一次自己決定要不要繼續繳稅。
  - 骨吉說：「這筆帳，我們一起還。」
  - 教授把筆記上的塗鴉裱框。
  - 米菈說「我早就說過了」，卻沒有領報酬就跟了上來。
  - 魔王第一次在白天走出城堡。
