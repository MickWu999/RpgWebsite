# ChatGPT 對話：橫向捲軸（LISA）與 3D 網頁 RPG

- 來源：使用者與 ChatGPT（免費版）的對話，2026-10-21 貼給 Claude Code
- 可信度：沒有附設計者出處，只當參考。素材網站的授權說法要以各網站的授權頁為準
- 本平台的結論見文末

## 對話重點

- RPG 的移動方式有兩種：平面地圖型（俯視角，上下左右自由走）與橫向捲軸型（像舞台，主要左右移動，鏡頭跟著走）。LISA: The Painful 在 Steam 上被描述為橫向捲軸 RPG。
- 若要 vibe 3D 網頁 RPG，要先決定鏡頭與移動：3D 橫向捲軸、3D 俯視角、3D 第三人稱、3D 第一人稱。技術建議 Babylon.js 或 Three.js。
- 3D 第三人稱的難點：角色控制（中等）、第三人稱鏡頭不穿牆（中高）、戰鬥與動畫連動（中高）。建議分階段：先能走動的世界 → 戰鬥 → 探索與任務 → 背包、存檔。
- 3D 素材來源：Quaternius（免費奇幻模型與動畫）、Mixamo（骨骼動畫）、Kenney（部分 CC0）、Poly Pizza、Sketchfab（各模型授權不同，部分要求署名）。Web 3D 優先用 .glb / .gltf。
- 給 AI 的原則：先完成一個角色、一隻怪物、一張小地圖的可玩版本，再擴充；記錄每個資產的來源與授權；找不到素材要明說，不要偽造網址。

## 本平台的結論（Claude Code 整理）

1. 目前維持 2D 俯視角。我們的整條流程（RPG Maker 事件模型、操作 API、自動試玩、設計防呆、審查）都建立在格子地圖上；改 3D 等於重做引擎，而故事好不好玩和 3D 無關。
2. LISA 是用 RPG Maker 2003 做的，「橫向捲軸」主要靠地圖設計與側面視角的美術營造（地圖做成橫向的走廊，上下只用在梯子、繩子）。這代表我們的格子引擎也能做出類似的手感：之後可以讓單張地圖設定成「側面視角」，換一套側面素材（例如 Kenney 的 CC0 平台遊戲素材），不必改事件與劇情的資料模型。
3. 引擎是純函式（src/game/engine.ts），和畫面（Phaser）分開。之後真的要換成 2.5D 或 3D 的畫面，故事與事件資料可以沿用。
4. 素材授權：Quaternius 標示為 CC0；Mixamo 是 Adobe 的服務條款，不是 CC0；Sketchfab、Poly Pizza 依各模型而定。依本專案「只用 CC0」的原則，3D 素材只考慮 Quaternius 與 Kenney 的 CC0 包。
